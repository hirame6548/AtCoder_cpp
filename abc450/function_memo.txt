### Python → C++ 競プロ文法 変換表

AtCoderで頻出する処理の書き換え方を整理しておく。前回VS Codeに登録したテンプレート（`rep`マクロや`all`マクロ、`ll`のエイリアス）を使う前提の記述だ。

#### 1. 変数と型
Pythonと異なり、C++ではすべての変数に「型」の宣言が必要だ。競プロで特に気を付けるべきは整数の上限で、通常の `int` は約 $2 \times 10^9$ までしか扱えない。それを超える場合は `long long`（テンプレートの `ll`）を使う。

```cpp
// Python: n = 10**18
ll n = 1e18;

// Python: s = "hello"
string s = "hello";

// Python: x, y = 10, 20
int x = 10, y = 20;
```

#### 2. 配列（1次元・2次元）
ここが最初の壁になる。C++では可変長配列として `vector` を使う。

```cpp
// --- 1次元配列 ---
// Python: a = [0] * N
vector<int> a(N, 0);  // 0で初期化（省略可）

// 要素の追加
// Python: a.append(5)
a.push_back(5);

// --- 2次元配列（グリッド） ---
// Python: grid = [[0] * W for _ in range(H)]
vector<vector<int>> grid(H, vector<int>(W, 0));
```

#### 3. 文字列操作
連結は `+` でそのままできるが、Pythonの強力なスライス機能は使えない。部分文字列の取得は `substr` を使うが、引数の意味が「終了位置」ではなく「文字数」であるという罠がある。

```cpp
// Python: s = "abc" + "def"
string s = "abc" + "def";

// Python: sub = s[1:4] (インデックス1から3まで、計3文字)
// C++: substr(開始位置, 文字数)
string sub = s.substr(1, 3);
```

#### 4. 辞書と集合 (Dict / Set)
Pythonの `dict` は `map`、`set` は `set` に対応する。メソッド名が変わる点に注意。

```cpp
// --- Set (集合) ---
// Python: s = set(); s.add(5); 5 in s
set<int> s;
s.insert(5);
if (s.count(5)) { /* 存在する場合の処理 */ }

// --- Dict (連想配列) ---
// Python: d = {}; d["apple"] = 10;
map<string, int> d;
d["apple"] = 10;
```

#### 5. ソートと反転
配列の操作には、標準ライブラリの関数とテンプレートの `all()` マクロを組み合わせる。

```cpp
// Python: a.sort()
sort(all(a));

// Python: a.sort(reverse=True) (降順)
sort(a.rbegin(), a.rend());

// Python: a.reverse()
reverse(all(a));
```

autoによる型推論


`auto` による型推論はC++11から標準搭載された機能だ。コンパイル設定で `-std=gnu++20`（C++20規格）を指定したため、すでに最新の推論機能までフルサポートされた状態になっている。

Pythonライクに書くため、競プロでは以下の3つの場面で非常に重宝する。

### 1. 範囲for文 (Range-based for)
配列の中身を直接取り出すとき、型の明記を省略できる。
```cpp
vector<long long> a = {1, 2, 3, 4};

// 読み取りのみ（Pythonの for x in a:）
for (auto x : a) {
    print(x); // 先ほど自作したprint関数
}

// 要素の書き換え（参照 & をつける）
for (auto& x : a) {
    x *= 2;
}
```

### 2. 構造化束縛 (C++17以降)
複数の戻り値や、ペア（タプル）を受け取るときにPythonのようにアンパックできる。
```cpp
pair<int, string> p = {10, "apple"};

// Pythonの x, y = p のように受け取れる
auto [x, y] = p;
```

### 3. 複雑な型の受け取り
C++の標準ライブラリ関数の戻り値（イテレータなど）は型名が異常に長くなることがあるため、それを `auto` で受けるのが標準的な書き方になっている。
```cpp
// 本来は std::vector<int>::iterator という長い型になる
auto it = lower_bound(all(a), 5);
```

---

### 唯一の注意点（Pythonとの違い）
C++の `auto` はあくまで「右側の値からコンパイラが型を推論し、**固定する**」機能だ。Pythonのように「動的に型が変わる」わけではない。

```cpp
auto x = 10; // OK (intと推論され、以後xは一生int型になる)
x = "hello"; // エラー (型の変更はできない)

auto y;      // エラー (右辺がないと推論できないため、初期化必須)
y = 20;
```

右辺を見れば型が明らかな場所や、構造化束縛などタイピングを減らしたい場所には、積極的に `auto` を使っていくといい。






入力の受け取り


int a, b, c;
cin >> a >> b >> c;


// vectorの入力を cin >> A のように一発でできるようにする設定
template <typename T>
istream& operator>>(istream& is, vector<T>& v) {
    for (auto& x : v) is >> x;
    return is;
}

これをプリアンプルに入れとけば、以下のように書ける

int N;
cin >> N;

vector<int> A(N);
cin >> A; // これだけでN個の要素すべてがAに格納される






// python における range

### 1. 単純なループ：自作マクロ `rep` を使う（使用率99%）
Pythonで `for i in range(N):` と書いていた処理は、すでにテンプレートに組み込んであるマクロを使うのが競プロ界隈の絶対的な標準だ。

```cpp
// Python: for i in range(N):
rep(i, N) {
    print(i);
}
```
これで「0からN-1まで」のループが回る。タイピング量もPythonの `range` より短く、最も思考を邪魔しない。

### 2. 連番の配列（リスト）を生成する：`std::iota`
Pythonの `list(range(N))` のように、0, 1, 2... と連番が入った配列の「実体」を作りたい場合は、標準アルゴリズムの `iota`（イオタ）を使う。

```cpp
vector<int> A(5);
iota(all(A), 0); // 0から順番に埋める

print(A); // 実行結果: 0 1 2 3 4
```
インデックス番号と要素の値を一致させておきたい初期化処理などで多用する。

### 3. Pythonの `range` の完全再現：`views::iota` (C++20)
君のコンパイル環境はすでにC++20に対応しているため、実はPythonの `range` と**設計思想まで完全に一致する**最新の標準機能が使える。

```cpp
// Pythonの for i in range(2, 6): と全く同じ
for (int i : views::iota(2, 6)) {
    print(i); // 実行結果: 2, 3, 4, 5
}
```
これは配列をメモリ上に作らず、「必要な時に次の数値を生成する」という機能（ジェネレータ）であるため、巨大な範囲を指定してもメモリを食いつぶさない。Pythonの `range` と全く同じパフォーマンス特性を持っている。

---

基本的にはタイピングが最速の `rep(i, N)` を使い、「aからbまで」のように開始位置が0以外のループを回したい時に `views::iota(a, b)` や標準の `for` 文を使う、という棲み分けが最も実戦的だ。

ループ関連で言えば、Pythonの逆順ループ `range(N-1, -1, -1)` や、1つ飛ばしの `range(0, N, 2)` に相当するC++の書き方も今のうちに整理しておくか？
